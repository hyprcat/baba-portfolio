## Visual / design note

- Don't use star ratings. They're cheesy and provoke "why is X 4/5 and Y 5/5" arguments.
- Don't use percentage bars ("Excel — 85%"). Same problem.
- Use a **plain table** or **two pill clouds**. Clear, honest, doesn't look like a recruiter scammed you into using their template.
- Type: same as body, no special treatment. The skills don't need to dance.
